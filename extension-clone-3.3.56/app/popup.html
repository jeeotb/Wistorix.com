Chào mừng đến với Wistorix

Wistorix giúp bạn quét Google Drive, phát hiện rủi ro và tối ưu dung lượng nhanh chóng.

📂
Đọc danh sách file
Xem tên, kích thước, ngày chỉnh sửa. Không thay đổi nội dung file của bạn.
🗑️
Quản lý file
Chuyển file vào thùng rác và thu hồi quyền chia sẻ — chỉ khi bạn ra lệnh.
👤
Thông tin tài khoản
Biết bạn đang đăng nhập bằng email nào để phân biệt file của bạn và file được chia sẻ.
💾
Lưu trữ trên trình duyệt
Lưu cài đặt và cache quét vào máy tính của bạn. Dữ liệu không rời khỏi thiết bị.
🔔
Thông báo
Gửi cảnh báo khi phát hiện file có rủi ro bảo mật hoặc chiếm dụng nhiều dung lượng.
